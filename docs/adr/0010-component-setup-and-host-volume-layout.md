# Component Setup, ensure-components, and Host Volume layout

Public Hosts still get Components (Service Network, then Edge) only **after** Initial Host Provisioning: IHP remains a carrier (engine, Prefect User, port floor, Host Volume mount) and does not run Component Setup or install Workloads — putting Setup inside cloud-init was rejected because SSH/copy is unsafe mid-IHP and user_data churn would recreate the Host for every Component change. Instead, operator-side `prefect/ensure-components.sh` waits for IHP, scp/tar-copies each Component tree onto the Host Volume as root, chowns to the Prefect User, and runs each Component’s idempotent `setup.sh` in a hardcoded order (`network`, then `edge`). Success means the Component **is in the correct state** (header contract on every Component Setup script). Workload Setup (thin Manifest → Workload Intent + operator Routes/Quadlets; ADR-0011 / ADR-0014 / ADR-0017 / ADR-0022 / ADR-0024) and Purge are separate paths; neither is invoked by ensuring Components. ensure-components also installs the Domain-derived ACME want-list and Domain fronts (ADR-0023 / ADR-0028). Edge Component Setup also installs on-demand ACME (ADR-0015).

**Host Volume layout:** mount root `/var/lib/prefect` stays root-owned; everything under it is Prefect User–owned. **Source** (repo mirror, scp-replaced): `/var/lib/prefect/components/{network,edge}/` — includes Edge `nginx.conf` (container bind-mounts it from here); no `certs/` in the source tree — plus shared Host-local helpers under `/var/lib/prefect/components/lib/` (not a Component; no `setup.sh`; sourced by Component Setup). **Data** (Host/Workload durable bytes): `/var/lib/prefect/components_data/edge/` — at least `routes/` (Workload Route fragments), `domains/` (Edge Domain fronts — ADR-0028), `certs/`, and an HTTP-01 webroot for ACME (ADR-0015); Component Setup ensures empty stubs into data `routes/` and `domains/` and never deletes other Route or Domain-front files it does not own; Quadlet units stay under the Prefect User’s home. Durable source on the volume lets Component Setup re-run after Host rebuild or Park→Apply without relying on IHP; Teardown removes the volume with the Stack (ADR-0016).

**Rejected:** Setup inside IHP; rsync; operator script named apply/provision (Stack apply / IHP collision); root-owned `components/` (blocks rootless binds); certs under the source mirror; wiping runtime routes on ensure; treating Workloads as Components.
