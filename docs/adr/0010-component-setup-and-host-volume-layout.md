# Component Setup, ensure-components, and Host Volume layout

Public Hosts still get Components (Service Network, then Edge) only **after** Initial Host Provisioning: IHP remains a carrier (engine, Platform User, port floor, Host Volume mount) and does not run Component Setup or install Workloads — putting Setup inside cloud-init was rejected because SSH/copy is unsafe mid-IHP and user_data churn would recreate the Host for every Component change. Instead, operator-side `internals/ensure-components.sh` waits for IHP, scp/tar-copies each Component tree onto the Host Volume as root, chowns to the Platform User, and runs each Component’s idempotent `setup.sh` in a hardcoded order (`network`, then `edge`). Success means the Component **is in the correct state** (header contract on every Component Setup script). Workload Setup (thin Manifest → Workload Intent + operator Routes/Quadlets; ADR-0011 / ADR-0014 / ADR-0017 / ADR-0022 / ADR-0024) and Purge are separate paths; neither is invoked by ensuring Components. ensure-components also stages the Domain-derived ACME FQDN list for Edge Setup to install into the Host want-list and reconcile Domain fronts (ADR-0023 / ADR-0028). Edge Component Setup also installs on-demand ACME (ADR-0015).

**Host Volume layout:** mount root `/var/lib/host-volume` stays root-owned; everything under it is Platform User–owned. **Source** (repo mirror, scp-replaced): `/var/lib/host-volume/components/{network,edge}/` — includes Edge `nginx.conf` (container bind-mounts it from here); authored units under `quadlets/` and `systemd/` by consumer (shape parity with Workloads; ADR-0034) — Component Setup installs those into the matching Platform User directories under authored basenames; no `certs/` in the source tree — plus shared Host-local helpers under `/var/lib/host-volume/components/lib/` (not a Component; no `setup.sh`; sourced by Component Setup). **Data** (Host/Workload durable bytes): `/var/lib/host-volume/components_data/edge/` — at least `routes/` (Workload Route fragments), `domains/` (Edge Domain fronts — ADR-0028), `certs/`, and an HTTP-01 webroot for ACME (ADR-0015); Component Setup ensures those data directories exist and never deletes Workload Route or Domain-front files it does not own; nginx empty-glob includes need no stub files. Quadlet and native user units stay under the Platform User’s home. Durable source on the volume lets Component Setup re-run after Host rebuild or Park→Apply without relying on IHP; Teardown removes the volume with the Stack (ADR-0016).

**Rejected:** Setup inside IHP; rsync; operator script named apply/provision (Stack apply / IHP collision); root-owned `components/` (blocks rootless binds); certs under the source mirror; wiping runtime routes on ensure; treating Workloads as Components.
