# Park keeps Durables; Teardown is explicit full wipe

Development and other non-production Environments need to drop the Host when idle (stop paying for compute you are not using) without losing stable public addressing, DNS, or Host Volume bytes (certs, Routes, ACME webroot) for a later Apply. **Destroy** (remove every managed resource) was the wrong default for that. We replace it with **Park** (remove Host and other non-durables; keep **Durables**), **Apply** (create missing resources and reattach Durables; fail fast if Durable assumptions do not hold), and **Teardown** (full wipe including Durables). Durables are the **Reserved IP**, the **Host Volume**, and the **Domain** (provider DNS zone plus Stack-authored records — see [ADR-0020](0020-domain-durable.md)). Park is a cost convenience for non-production — not the normal path for production. This supersedes ADR-0009’s “survive Host recreate, not Destroy” deferral — that need is now real.

**Operator UX:** `./apply.sh` is Apply (interactive Terraform confirm by default; `--yes` for automation; `--env <slug>` for Environment selection per [ADR-0019](0019-environments.md) — specialist Stack surgery stays raw `terraform` in the Stack dir). `./park.sh` Parks for idle non-production use (warn that Durables still bill; same `--env` rule). `./teardown.sh` requires typing `teardown` for the explicit full wipe when Durable billing should stop (same `--env` rule). Default with no `--env` is the **test** Environment (workspace `default`); `test` and `default` are aliases.

**Terraform:** `lifecycle.prevent_destroy` on Durables (default on; must be a literal — Terraform cannot read a variable here). Teardown lifts the guard by writing a gitignored override (`durable_destroy_override.tf`) that sets `prevent_destroy = false` **and** passing `-var=allow_durable_destroy=true` (default false); a Stack precondition keeps those two aligned so raw destroy without both stays fail-closed. Reserved IP is split: address resource (Durable) + `digitalocean_reserved_ip_assignment` (non-durable, destroyed on Park, recreated on Apply). Host Volume stays a separate resource with `volume_ids` on the Host. Domain is an aggregate Durable (zone + Stack-authored record resources) with the same `prevent_destroy` / Teardown unlock posture. Unassigned Reserved IP stays in Cloud Project Prefect while Parked via preserved `digitalocean_project_resources.reserved_ip` (`do:floatingip:<ip>` — see [ADR-0003](0003-cloud-project-owns-hosts.md)).

**Tests:** Acceptance Tests stay non-destructive on an Applied Stack (Host present); they must not Park or Teardown. Lifecycle Tests (`lifecycle-test.sh`) are a separate opt-in suite for Park / Apply-after-Park / Teardown.

**Considered:** Redefine Destroy with a flag; compose-style up/down/teardown; keep Destroy as full wipe and add Park only; targets without `prevent_destroy`; `state rm` Durables. Rejected for accident risk, glossary collision with Workload **Purge**, or failing open on raw `terraform destroy`.
