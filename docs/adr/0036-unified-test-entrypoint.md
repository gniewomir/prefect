# Unified test entrypoint and suite layout

Propraetor’s executable checks are three suites — **Acceptance**, **Lifecycle**, and **Unit** — each a subdirectory of `internals/test/` (`acceptance`, `lifecycle`, `unit`). One root entrypoint `./test.sh` dispatches by mandatory suite name to `internals/test/<suite>/run.sh`. Accepted shapes: `./test.sh <suite> [<case-selector>] [--env <slug>]` (and the same without a case selector); `--env` is only valid for `acceptance` and `lifecycle` (fail closed on `unit`); invalid invocation prints help and exits non-zero. Unit Tests stay colocated as `internals/**/*_test.sh` and are discovered by the unit runner; Acceptance/Lifecycle cases remain numeric-prefixed slices under their suite dirs. Hard cut (ADR-0018): old `internals/acceptance-tests.sh` / `lifecycle-tests.sh` and matching top-level suite dirs go away in the same change — no wrapper shims. Agent discovery: `docs/agents/testing.md` via `AGENTS.md`. Amends ADR-0005 (harness location) and ADR-0032 (`./test.sh` joins root operator surface; suite trees live under `internals/test/`).
