# Unified test entrypoint and suite layout

Propraetor’s executable checks are three suites — **Acceptance**, **Lifecycle**, and **Unit** — each a subdirectory of `internals/test/` (`acceptance`, `lifecycle`, `unit`). One root entrypoint `./test.sh` dispatches by mandatory suite name to `internals/test/<suite>/run.sh`. Accepted shapes: `./test.sh <suite> [<case-selector>] [--verbose] [--env <slug>]` (and the same without a case selector); positionals first, then flags (ADR-0039); `--verbose` (or `TEST_VERBOSE=1`) streams case output live instead of quiet-on-pass buffering; `--env` is valid for `acceptance` (non-**test** confirm-gated) and for `lifecycle` only as **test**/**default** (ADR-0042); fail closed on `unit`; invalid invocation prints help and exits non-zero. Unit Tests stay colocated as `internals/**/*_test.sh` and are discovered by the unit runner; Acceptance/Lifecycle cases remain numeric-prefixed slices under their suite dirs. Hard cut (ADR-0018): old `internals/acceptance-tests.sh` / `lifecycle-tests.sh` and matching top-level suite dirs go away in the same change — no wrapper shims. Agent discovery: `docs/agents/testing.md` via `AGENTS.md`. Suite baselines / isolation: ADR-0042. Amends ADR-0005 (harness location) and ADR-0032 (`./test.sh` joins root operator surface; suite trees live under `internals/test/`).
