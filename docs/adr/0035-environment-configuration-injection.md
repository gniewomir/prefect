# Environment Configuration reaches Workloads via EnvironmentFile

Operators need non-committed, Environment-scoped key/value configuration in Workload containers without putting secrets in the repository or substituting values into unit/config text. Research showed plain placeholder→value substitution into systemd/Quadlet grammar is unsafe for arbitrary values; Quadlet `EnvironmentFile=` (and Setup-owned drop-ins) keeps values out of unit text while Host Volume SoT stays authored Manifest + units/routes. This ADR records that contract. Glossary term: **Environment Configuration**. Manifest allowlist thicken: ADR-0024. Purge of install artifacts: ADR-0014. Wayfinder map [Operator-supplied configuration for Workloads and Components](https://github.com/gniewomir/prefect/issues/106) is the decision audit trail.

**Contract (v1).** One Environment-scoped bag per Prefect Environment. Baseline from gitignored `environments/<slug>/.env` when present; current shell overrides any key; if no file, requested keys come from the shell. Workload Manifest optional `environment` array of key names (omit/`[]` ⇒ none). Workload Setup materializes **only the listed names** into **one** Platform User–local EnvironmentFile at `~/.config/platform/workloads/<basename>/environment` and wires it via Setup-owned Quadlet drop-ins (`EnvironmentFile=` on each install copy of that Workload’s `quadlets/*.container`). Surplus bag keys (in `.env` or the shell) that the Manifest does not list are ignored for that Workload — not an error. Missing listed keys fail closed in Setup. A non-empty `environment` list with no `quadlets/*.container` fails closed (v1 injection is Quadlet-only; omit/`[]` with no containers is fine). Re-Setup is the rotation path: it rewrites the EnvironmentFile from current sources; omit/`[]` removes those artifacts; **stop** / **trash** retain them until Purge; Purge removes the EnvironmentFile tree and Setup drop-ins. Values never appear in unit grammar or on the Host Volume Workload tree. Native `systemd/` units are out of v1 for this path. **Workloads only** — Components neither declare nor receive EnvironmentFiles in v1. Provider **Credential** (`DIGITALOCEAN_TOKEN` today) stays orthogonal.

**Operator file conventions.** Strict dotenv subset for `.env` (`KEY=value`, `#`/blanks, optional double quotes; no `export`, interpolation, or multiline). Gitignore `*/.env` under `environments/`. Required committed `.env.example` per operator-facing Environment (Setup does not read it). Key names are operator-owned — Setup does not reserve or reject names — but prefer not to use `PLATFORM_*` or Credential names in Manifest `environment` or `.env.example`.

**Rejected:** plain textual substitution / placeholders for this path; bag values in `Environment=` or other unit grammar; Host Volume as the value store; Host vaults / cloud secret managers; folding Credential into the bag; Component EnvironmentFiles in v1; Setup reserved-name enforcement; live reload or a separate rotate command without Setup.

**Deferred to `/to-spec` / implementation planning (not this ADR):** drop-in basenames, Setup script module layout, parser internals, teaching/`environments/example/` cutover, Acceptance/Lifecycle Test design, operator-facing rotation UX beyond re-Setup rewrite, CI shell-only ergonomics, and when Components might later consume the bag.
